# User Stories for Domain: NetBeans

## [US-000024] Access QuickQuestion as an LLM helper inside the NetBeans IDE
**As a** Developer,
**I want** to open and use the QuickQuestion LLM chat selector inside the NetBeans IDE,
**So that** I can quickly query an LLM while working on code without leaving the IDE.

### Technical Context & Constraints
* **Target System**: NetBeans IDE module (Swing-based host)
* **Toolchain / Rules**: NetBeans Module Development, JavaFX, JFXPanel, Maven, TDD workflow, headless testing where applicable

### Acceptance Criteria
```gherkin
Scenario: Developer opens the QuickQuestion window from within NetBeans
  Given the QuickQuestion NetBeans module is installed
  When the developer invokes the QuickQuestion window action
  Then a NetBeans window containing the QuickQuestion component opens

Scenario: Developer selects an LLM from the QuickQuestion window inside NetBeans
  Given the QuickQuestion window is open inside NetBeans
  And a list of LLM providers is configured
  When the developer selects a provider from the LLM selector
  Then the embedded WebView navigates to that provider's web chat URL

Scenario: Developer closes and reopens the QuickQuestion window in NetBeans
  Given the QuickQuestion module is installed in NetBeans
  And the developer has previously used the QuickQuestion window
  When the developer closes and reopens the QuickQuestion window
  Then the previous WebView session is restored

Scenario: Developer switches between LLM providers inside NetBeans
  Given the QuickQuestion window is open inside NetBeans
  And multiple LLM providers are configured
  When the developer selects a different provider
  Then the WebView loads the newly selected provider's chat page

## Status

```
