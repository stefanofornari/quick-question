# User Stories for Domain: demo

## [US-000006] Install Tiger VNC Server
**As a** User,
**I want** the demo application to check at startup whether the VNC server binaries
  are already installed in `${user_data_dir}/quickquestion/tigervnc-1.16.2.x86_64`
  and install them if needed,
**So that** the demo works seamlessly without manual setup.

### Technical Context & Constraints
* **Target System**: JavaFX desktop applications
* **Toolchain / Rules**: JavaFX, Maven, bundled native binaries, user data directory installation

### Acceptance Criteria
```gherkin
Scenario: VNC Server Binaries Already Installed
  Given the demo application is starting up
  And the directory `tigervnc-1.16.2.x86_64` is already present under `${user_data_dir}/quickquestion`
  When the startup check runs
  Then the application proceeds without modifying the existing installation

Scenario: VNC Server Binaries Missing
  Given the demo application is starting up
  And the directory `tigervnc-1.16.2.x86_64` is not present under `${user_data_dir}/quickquestion`
  When the startup check runs
  Then the application extracts the bundled VNC server archive into `${user_data_dir}/quickquestion`

Scenario: VNC Server Package Not Found
  Given the demo application is starting up
  And the VNC server package archive is not found
  When the startup check runs
  Then the application shows an error message on the console
  And the application exits
```
